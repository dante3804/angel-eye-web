# Angel-Eye 랜딩 페이지 — 레포 통합 가이드

기존 `보호자 대시보드` 화면을 이 랜딩 페이지로 완전히 대체하는 절차야.
(대시보드 코드 자체는 git 히스토리에 남아있으니, 나중에 필요하면 언제든 복구 가능해.)

---

## 1. 파일 배치

`angel-eye-web` 레포의 `src/` 안에 아래 두 파일을 넣어줘 (경로는 프로젝트 구조에 맞게 조정 가능):

```
src/
  pages/
    LandingPage.jsx   ← 여기에 복사
    LandingPage.css   ← 여기에 복사
```

## 2. App.jsx (또는 진입점) 수정

기존에 대시보드 컴포넌트를 렌더링하던 부분을 찾아서 교체:

```jsx
// 기존 (예시)
import Dashboard from "./pages/Dashboard";

function App() {
  return <Dashboard />;
}
```

```jsx
// 변경 후
import LandingPage from "./pages/LandingPage";

function App() {
  return <LandingPage />;
}
```

파일명/컴포넌트명이 다르면 실제 이름에 맞춰서 바꿔줘. 만약 어떤 파일을 고쳐야 할지
모르겠으면, `src/App.jsx`를 직접 보여주면 정확한 수정 위치를 짚어줄게.

## 3. 로컬에서 확인

```bash
cd ~/Desktop/angel-eye-web
npm run dev
```

브라우저에서 `http://localhost:5173` (또는 표시된 포트) 열어서 확인.

## 4. 에셋 교체 (placeholder → 실제 자료)

`LandingPage.jsx` 안에 `[PLACEHOLDER]`로 표시된 4곳이 있어:
- 히어로 대표 스크린샷
- 스켈레톤 오버레이 스크린샷
- 알림 화면 스크린샷
- 데모 영상

`AssetPlaceholder` 대신 실제 이미지/영상 태그로 교체하면 돼. 예:

```jsx
<img src="/assets/hero-screenshot.png" alt="Angel-Eye 대시보드 화면" className="ae-real-shot" />
```

## 5. Git 브랜치 작업 (main/develop 전략에 맞춰)

```bash
git checkout develop
git pull origin develop
git checkout -b feature/landing-page-redesign

# 파일 추가 및 App.jsx 수정 후
git add .
git commit -m "feat: 랜딩 페이지로 대시보드 화면 대체"
git push -u origin feature/landing-page-redesign
```

이후 GitHub에서 **base: develop**으로 PR 생성 → 리뷰 → 머지.
최종적으로 develop → main PR까지 머지되면 `npm run deploy`로 배포.

## 6. 배포 후 재검증

배포 URL을 다시 열어서, 이번엔 실제로 랜딩 페이지가 뜨는지 확인해줘.
필요하면 여기서 다시 스크린샷 캡처해서 비교해줄게.
